Como instalar

  1. Toque em Baixar para Android pelo celular.
  2. Abra o arquivo saldo.apk quando o download terminar.
  3. Se o Android avisar sobre apps de fontes desconhecidas, toque em Configurações e permita instalar a partir do navegador.
  4. Toque em Instalar e abra o Saldo.

Para atualizar, é só baixar de novo por este mesmo link: a versão nova instala por cima e seus dados continuam no servidor.
